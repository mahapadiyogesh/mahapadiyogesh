## 🚀 About InsightFlowAI

**InsightFlowAI** is an AI-assisted web application focused on automated data analysis and dynamic dashboard generation.

The project is designed to transform uploaded datasets into useful analytical components such as:

- 📊 KPIs
- 📈 Charts
- 🎛️ Filters
- 💡 Insights
- 🗂️ Data tables
- 🖥️ Interactive dashboards

### Core Idea

```text
Upload Data
     ↓
Analyze Dataset
     ↓
Understand Columns
     ↓
Generate KPIs
     ↓
Generate Charts
     ↓
Generate Filters
     ↓
Generate Insights
     ↓
Build Dashboard


🎯 Project Objective

The main objective of InsightFlowAI is to reduce the manual effort involved in creating analytical dashboards.

Instead of manually deciding which KPIs, charts, filters, and insights should be used, the application is being developed to generate these components based on the uploaded dataset.

✨ Key Features
📂 Dataset Analysis
Analyze uploaded datasets
Detect column types
Understand dataset structure
Prepare data for analysis and visualization
